================================================================================
 EzzyHub vs. Wang et al. (QRS 2022) - iTrust Requirement-to-Code Traceability
================================================================================

WHAT THIS FILE IS
--------------------------------------------------------------------------------
This compares EzzyHub against the published results of Wang et al. (QRS 2022)
on the SAME public dataset (iTrust) using the SAME accuracy measures, so the
two can be read directly side by side.

Dataset: iTrust   |   Requirements: 131   |   Code files: 226   |   True links in the answer key: 286

Three definitions (for every one, higher = better):
  - Recall     : of all the CORRECT requirement->code links, how many were found.
  - Precision  : of all the links the tool REPORTED, how many were actually correct.
  - F-measure  : one balanced score that combines recall and precision.


VIEW 1 - TRACE-LINK RETRIEVAL (this is the view the paper reports)
--------------------------------------------------------------------------------
At each recall level, EzzyHub and the paper are shown together. 'Same recall'
means both found the same share of the true links; the gap is then in precision
(how many extra wrong candidates came along).

  Recall level             Metric       EzzyHub     Paper   Difference
  --------------------------------------------------------------------
  Acceptable (~60% recall) Recall        61.19%    64.12%    -2.93 pts
                           Precision      5.79%    12.93%    -7.14 pts
                           F-measure     10.58%    21.53%   -10.95 pts
  --------------------------------------------------------------------
  Good (~70% recall)       Recall        72.03%    70.57%    +1.46 pts
                           Precision      3.40%     9.06%    -5.66 pts
                           F-measure      6.49%    16.06%    -9.57 pts
  --------------------------------------------------------------------
  Excellent (~80% recall)  Recall        81.12%    80.38%    +0.74 pts
                           Precision      1.61%     4.54%    -2.93 pts
                           F-measure      3.16%     8.59%    -5.43 pts
  --------------------------------------------------------------------

  How to read it: EzzyHub reaches the SAME recall levels as the paper (it finds
  just as many of the true links), but at lower precision in this raw view - to
  find those links it also proposes many more candidate pairs. That is the normal
  recall/precision trade-off; the paper's method is tuned to output fewer, cleaner
  candidates in this specific ranking.


VIEW 2 - EZZYHUB'S ACTUAL VERDICT: IMPLEMENTED / PARTIAL / MISSING
--------------------------------------------------------------------------------
The paper only outputs a ranked list of candidate links. EzzyHub goes further and
gives each requirement a real verdict. This view scores THOSE verdicts against the
answer key. (The paper has no equivalent output, so this section is EzzyHub only.)

  When EzzyHub says a requirement IS implemented:
      Correct (true positive) :    7
      Wrong   (false positive):    1
  When EzzyHub says a requirement is MISSING:
      Correct (true negative) :    2
      Wrong   (false negative):    4
  Marked PARTIAL (left for a human to judge):  117
  ----------------------------------------------------
  Total requirements:  131

  Precision of the 'IMPLEMENTED' verdict  : 87.50%
      -> when EzzyHub says a requirement is done, it is right this often.
  Recall of truly-implemented requirements : 63.64%
      -> of the requirements that really are done, EzzyHub catches this share.
  Overall accuracy (clearly-right verdicts): 6.87%
      -> the PARTIAL cases are counted as neither right nor wrong, which is why
         this looks lower than the precision above.


BOTTOM LINE
--------------------------------------------------------------------------------
  - On the paper's own trace-link measure, EzzyHub MATCHES the paper on recall at
    every level, and trails on precision (it proposes more candidate links).
  - On EzzyHub's real product output, when it declares a requirement IMPLEMENTED it
    is correct 87.50% of the time - a high-confidence verdict the paper's
    method does not itself provide.
